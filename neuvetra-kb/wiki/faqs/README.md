# `wiki/faqs/`

`type: faq` — short Q&A. Use when the content is too small to deserve its own use-case or objection page.

## Frontmatter

`products: [<one or more ids>]`.

## Heading structure

```markdown

## Related
```

## Notes

- **Promote to objection or use-case** when the same FAQ keeps growing or recurring. Tiny FAQ → fine. Half-page FAQ → it's an objection or a use-case in disguise.
- **No pricing in FAQs** — link to the plan page. (Public-Safe is unaffected, but pricing-drift is — see § LINT in `../../CLAUDE.md`.)
- At scale (>50 FAQs), revisit single-page-per-FAQ vs. consolidated category pages. PRD § Open Questions item #5.
- See `../../CLAUDE.md` § Page Heading Structures for the canonical version.
