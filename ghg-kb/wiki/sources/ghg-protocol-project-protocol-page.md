## Key Takeaways

1. **Confirms the Project Protocol's scope and audience.** Explicitly written for project developers, program administrators, third-party verifiers. Explicitly *not* for corporate or entity-wide GHG inventories — the Corporate Standard serves that purpose.

2. **Two supplementary documents exist that are not yet ingested:**
   - *LULUCF Guidance for GHG Project Accounting* — Provides more specific terminology and concepts for Land Use, Land-Use Change, and Forestry project activities. Developed by WRI; launched at COP-12, Nairobi, November 2006.
   - *Guidelines for Grid-Connected Electricity Projects* — Detailed guidance on accounting for GHG reductions from projects that displace or avoid grid power generation. Available in Japanese.

3. **No new technical content.** All substantive accounting principles, procedures, and concepts are covered in the full PDF already ingested (`ghg-protocol-project-accounting`).
