## Key Takeaways

1. **Three approaches:** Screening (E = AE + OE + DE: assembly + operating + disposal); Sales-Based (recommended for equipment manufacturers — tracks service charges and refrigerant sales); Lifecycle Stage (full lifecycle tracking).

2. **Sales-Based Approach is most accurate for equipment users:** tracks all refrigerant top-ups and service events, capturing the cumulative leakage that occurs between recharges. Requires service records.

3. **GWP table for common blends is included:** the tool provides GWP100 values for common refrigerant blends (R-507A = 3,300; R-410A not listed individually — use component blending). Note: these are older pre-AR5 values; use IPCC AR6 from the external database for current reporting.

4. **Equipment lifecycle phases:** assembly/installation (1–3% of charge), annual operation (leak rates vary by equipment type), disposal (charge remaining × recovery efficiency). All three phases must be summed.

5. **Screening only for materiality:** the tool explicitly states the screening approach should not substitute for Sales-Based or Lifecycle when refrigerants are material.
