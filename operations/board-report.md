# Neuvetra board update

**The data connections are mapped. Cloud integration is next; answer quality remains below the release gate.**

- **Found:** The old demo rejected ordinary vocabulary before reading evidence. Its model received five fixed statements, not the supporting document paragraphs. More question rules would preserve that limitation.
- **Changed:** A separate pipeline now selects from 18 reviewed EPA paragraphs by meaning, covers each requested part, resolves references on the server and checks claims against their own cited evidence. It distinguishes missing coverage from drafting, review and service failures.
- **Tested:** 118 API tests and 11 website-response tests pass; typechecking, website build and repository lint pass. Real answer quality does not yet pass: the latest eight-question run had two independently sound answers, one deficient released answer and five withheld answers. The previous configuration produced four sound answers, including the exact sourcing question. Neither passed the overall gate.
- **Connections:** The preview and reviewed source files are local; experimental AI calls use Anthropic's cloud. The current answer path uses neither Pinecone nor Supabase. Supabase API access now passes two read-only metadata checks; storage lists no buckets. Pinecone access and live index contents remain unverified.
- **Decision:** Use cloud Pinecone and Supabase for the next development integration. Stop local Docker setup. Hold answer release and keep the answering process stopped. Preserve the failed runs and code versions in unmerged PR #2; do not advance to calculations.
- **Next:** Verify cloud accounts and development targets, then test source storage, indexing, retrieval and exact citation resolution against the [proposed integration gate](../docs/research/cloud-integration-gate.md). Both dashboards currently require sign-in. In parallel, the proposed correction process and missed-condition benchmark still need implementation and evaluation; connecting storage does not solve false reviewer approvals.
