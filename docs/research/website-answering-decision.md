# Private website answering decision

September 9, 2026. The board reported that the actual website still returned an unreachable or unusable service error. Inspection found the frontend proxy addressed port 3012, where the research service was stopped, while the separate evaluation candidate listened on 3016. Publishing cloud evidence and obtaining direct API results had not demonstrated the website.

The form now preserves a question while disconnected, prevents submissions until the answering service is ready, and offers a connection check. Promotion requires the accepted service on the proxy's actual port and fresh questions submitted through the browser. Production startup and deployment settings remain unchanged.

## Answer construction

Generated-answer experiments also found a separate quality problem. Even with exact source quotes, a source-condition ledger and a second model checking each claim, drafting could introduce an unsupported causal relationship or omit a prerequisite. Revisions01–04 failed and remain preserved with their evaluation evidence.

The private preview now selects from 22 independently reviewed explanation units covering the 18 approved EPA passages. Models interpret the whole question, select explanation IDs and check the resulting composition. The server renders only the approved wording, fixed titles, source references and summary/interpretation labels. The browser validates that same contract before display. Live Supabase and Pinecone evidence checks remain mandatory; local explanation wording is not an offline source fallback.

This bounds factual wording without claiming universal accuracy. Selection can still be irrelevant, incomplete or inappropriate to the requested action. Revision05 demonstrated that distinction: all displayed wording matched the approved catalog, but one excluded eligibility request received a qualified conceptual answer. Two other correct planner boundaries were challenged by the reviewer, and one supported question exceeded the response limit. That run is failed, not a release success.

## General correction

Revision06 supplies server-measured companion closures and character costs before selection. A fully valid selection that exceeds the unchanged eight-unit/4,000-character limit can be replaced once, then independently reviewed. Content is never shortened and companions are never dropped to fit. Size correction and semantic correction share one allowance, for two normal stages, three stages after size correction, or four after semantic correction. Malformed IDs, source failures and exhausted corrections do not gain retries.

Both model instructions preserve the user's requested action: related conceptual guidance cannot replace an excluded determination, and an unsupported material facet requires a whole-question boundary response. General possible drivers remain distinct from establishing a particular company's actual cause. Selection/review validation failures have their own review status rather than masquerading as a lost connection.

The unchanged eighteen-question baseline, two unchanged first-attempt cross-concept probes, and actual browser results are separate gates. [Independent QA](website-cloud-qa.md) records their actual outcome. This decision document does not itself establish a passing run. [The runtime runbook](website-composed-runtime.md) describes operation, budgets, source expiry and remaining limits.

The baseline passed. One cross-concept probe then exposed a typographic validation failure: a curly apostrophe in the question was copied as a straight apostrophe in a question fragment. Revision06b permits only curly/straight single and double quote equivalence for that question-fragment comparison. It does not normalize source quotes, alter the original question, relax word/case/spacing checks or change model instructions. Independent QA accepted targeted verification: all eighteen recorded plans/reviews replayed unchanged, two explicitly labeled correction follow-ups passed, and the actual website was demonstrated. The original probe failure remains recorded.

Calculations, company-specific factors, instrument eligibility, filing obligations, customer authentication and production deployment remain outside this private milestone. Independent AI reviews are not professional accounting assurance or legal approval.
