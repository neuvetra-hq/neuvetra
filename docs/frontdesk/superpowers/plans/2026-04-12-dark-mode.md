# Dark / Light Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a dark/light theme toggle to the dashboard header that persists across sessions via localStorage.

**Architecture:** A `ThemeProvider` context manages theme state, toggles the `.dark` class on `document.documentElement`, and persists to `localStorage`. A `Sun`/`Moon` icon button in the dashboard header (pinned top-right) calls `toggleTheme()`. The CSS variables for `.dark` are already fully defined in `index.css` — no CSS changes needed.

**Tech Stack:** React 19, Tailwind v4 (class-based dark variant via `.dark` on `<html>`), lucide-react, shadcn Button

**Spec:** `docs/superpowers/specs/2026-04-12-dark-mode-design.md`

## Task 1: ThemeContext

**Files:**
- Create: `apps/web/src/contexts/ThemeContext.tsx`

- [ ] **Step 1: Create the context file**

```tsx
// apps/web/src/contexts/ThemeContext.tsx
import { createContext, useContext, useEffect, useState } from "react"

type Theme = "light" | "dark"

interface ThemeContextValue {
  theme: Theme
  toggleTheme: () => void
}

const ThemeContext = createContext<ThemeContextValue | null>(null)

export function ThemeProvider({ children }: { children: React.ReactNode }) {
  const [theme, setTheme] = useState<Theme>(() => {
    return (localStorage.getItem("theme") as Theme) ?? "light"
  })

  useEffect(() => {
    const root = document.documentElement
    if (theme === "dark") {
      root.classList.add("dark")
    } else {
      root.classList.remove("dark")
    }
    localStorage.setItem("theme", theme)
  }, [theme])

  const toggleTheme = () => setTheme((t) => (t === "light" ? "dark" : "light"))

  return (
    <ThemeContext.Provider value={{ theme, toggleTheme }}>
      {children}
    </ThemeContext.Provider>
  )
}

export function useTheme(): ThemeContextValue {
  const ctx = useContext(ThemeContext)
  if (!ctx) throw new Error("useTheme must be used within ThemeProvider")
  return ctx
}
```

```tsx
import { Sun, Moon } from "lucide-react"
import { useTheme } from "@/contexts/ThemeContext"

function ThemeToggle() {
  const { theme, toggleTheme } = useTheme()
  return (
    <Button
      variant="ghost"
      size="icon"
      onClick={toggleTheme}
      className="size-8 text-muted-foreground hover:text-foreground shrink-0"
      aria-label="Toggle theme"
    >
      {theme === "dark" ? <Sun /> : <Moon />}
    </Button>
  )
}
```
