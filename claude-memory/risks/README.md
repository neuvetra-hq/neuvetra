# risks/

Open risks, threats, dependencies, things that could break. The "what could go wrong" register.

Page type: `risk` (added 2026-04-25 via [[2026-04-25-skill-and-wiki-framework]]).

Examples (when populated):
- "Both products share Anthropic — a Claude outage takes both down"
- Regulatory risks for Terrascope (CARB MRR penalty exposure)
- Concentration risks (single vendor, single deploy target, single domain registrar)

Each page captures: the risk, likelihood, impact, mitigation if any, and the trigger conditions that would escalate it. Lifecycle: `status: open` → either `closed` (mitigated, deprecated) or `superseded` by a follow-up risk.
