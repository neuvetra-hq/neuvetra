# metrics/

KPIs, OKRs, what we measure. Pages describe **what** we track and **why**, not the values.

Page type: `metric` (added 2026-04-25 via [[2026-04-25-skill-and-wiki-framework]]).

Examples (when populated):
- Trial-to-paid conversion (FrontDesk)
- Time-to-first-emission-line for new Terrascope users
- North-star definitions per product

**Live values do not live here.** Per `wiki/CLAUDE.md` § Writing Conventions: numerical/live data lives in databases/dashboards. Metric pages document the definition, methodology, and provenance.

Cross-link `measures:` from `metrics/` to the `features/` or `products/` pages they describe once that edge type lands. Until then, use `related:`.
