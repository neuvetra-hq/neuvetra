# ideas/

Early-stage thinking. Not yet a feature, decision, plan, sales motion, or marketing campaign.

Page type: `idea` (added 2026-04-25 via [[2026-04-25-skill-and-wiki-framework]]).

Examples (when populated):
- "What if FrontDesk plugged into Slack first?"
- "Could the Spirit drive the favicon too?"
- Speculative product/sales/marketing concepts that surfaced in conversation but haven't been pushed forward

Lifecycle: ideas either get **promoted** to `features/`, `decisions/`, `plans/`, `sales/`, `marketing/` etc. (set `supersedes:` on the new page back to the idea), or **parked** (`status: parked`) when they're not pursued. Don't delete; the conversation that birthed them is part of the wiki's memory.
