# Topics

Cross-cutting subjects that don't fit cleanly under one product, plan, or tech — pricing, hiring, fundraising, legal, GTM channels, partnerships.

Topics are **emergent** — don't pre-create. When a conversation makes it clear a topic deserves its own page, file one here.

## Filename
`<topic-slug>.md` — kebab-case, globally unique.
